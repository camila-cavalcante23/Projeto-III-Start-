<h1>📌 StartUFC</h1>

**Portal Interativo para o Ecossistema de Startups**  
O StartUFC é um sistema web interativo e informativo dedicado ao ecossistema de startups, desenvolvido para conectar usuários e administradores, centralizando informações sobre startups, eventos, notícias e galerias.

A plataforma promove a interação entre usuários e facilita o gerenciamento e organização de dados e eventos, sendo uma ferramenta essencial para acompanhar o desenvolvimento e as atividades do setor.

<h2>🚀 Visão do Projeto</h2>

O StartUFC tem como objetivo criar uma plataforma web moderna, intuitiva e funcional que integre todas as informações relacionadas ao programa, proporcionando uma experiência unificada para:

- Divulgação de conteúdos  
- Participação em eventos  
- Interação com a comunidade  

<h2>🛠 Tecnologias Utilizadas</h2>

**Frontend**
- React.js
- Axios
- React Router
- React Icons
- HTML5, CSS3, JavaScript ES6+

**Backend**
- C# (.NET)
- SQL Server

**Infraestrutura**
- Docker & Docker Compose
- Git & GitHub
